一、项目概述
================================================================================

1.1 项目简介
    本项目是一个基于微信小程序原生框架开发的咖啡电商小程序，提供商品浏览、
    搜索、购买、订单管理、优惠券领取等完整的电商功能。同时集成了AI智能助手
    功能，提供智能推荐和对话服务。

1.2 核心功能
    - 商品展示与浏览（首页、菜单页）
    - 商品搜索（支持搜索历史、AI智能推荐）
    - 购物车管理
    - 订单管理（创建、支付、查看、状态跟踪）
    - 收货地址管理
    - 优惠券系统（领取、使用、每日更新）
    - 用户登录注册
    - AI智能助手（基于Coze平台）

1.3 技术特点
    - 使用微信小程序原生框架，性能优异
    - 统一的UI设计规范，主题色：#0C34BA
    - 本地存储管理，数据持久化
    - AI智能推荐功能
    - 每日更新的优惠券系统

4.7 优惠券系统
    4.7.1 优惠券列表（pages/coupons/coupons）
        功能：
        - 优惠券分类（可用、已使用、已过期）
        - 优惠券列表展示
        - 跳转到领取页面
        
        核心方法：
        - onLoad(): 加载优惠券列表
        - loadCoupons(): 加载并筛选优惠券
        - switchTab(): 切换标签
        - goToGetCoupon(): 跳转到领取页面
        
        数据存储：
        - coupons: 优惠券列表（本地存储key: 'coupons'）
    
    4.7.2 领取优惠券（pages/getCoupon/getCoupon）
        功能：
        - 显示当天累计消费金额
        - 优惠券解锁进度显示
        - 通过消费金额解锁优惠券
        - 每日重置机制
        
        解锁规则：
        - 消费满50元：5元无门槛优惠券
        - 消费满100元：10元无门槛优惠券
        - 消费满200元：20元满100减优惠券
        - 消费满500元：50元满200减优惠券
        
        核心方法：
        - checkAndResetDailyData(): 检查并重置每日数据
        - calculateTodaySpent(): 计算当天消费金额
        - loadAvailableCoupons(): 加载可领取优惠券
        - receiveCoupon(): 领取优惠券
        - getTodayDateString(): 获取今天日期字符串
        
        数据存储：
        - couponLastDate: 最后访问日期（本地存储key: 'couponLastDate'）
        - dailyCouponReceived: 当天领取记录（本地存储key: 'dailyCouponReceived'）
        
        每日更新机制：
        - 每天00:00自动重置领取状态
        - 只统计当天的订单消费
        - 每天可以重新领取已解锁的优惠券

五、核心功能实现
================================================================================

5.1 搜索功能
    5.1.1 搜索历史
        实现方式：
        - 使用wx.getStorageSync/wx.setStorageSync存储搜索历史
        - 最多保存10条历史记录
        - 自动去重，相同关键词移到最前面
        - 支持删除单条和清除全部
        
        存储key: 'searchHistory'
        数据结构: ['关键词1', '关键词2', ...]
    
    5.1.2 AI智能推荐
        实现方式：
        - 使用Coze AI平台API
        - 点击搜索框时自动加载推荐
        - 推荐5个热门搜索关键词
        - 点击推荐关键词直接搜索
        
        API配置：
        - 文件：utils/coze.js
        - BOT_ID: '7587462701082411042'
        - API_URL: 'https://api.coze.cn/v3/chat'
        - 使用流式响应处理

5.2 购物车功能
    实现方式：
    - 使用app.globalData.cart存储购物车数据
    - 同时同步到本地存储（key: 'cart'）
    - 支持添加、删除、修改数量
    - 支持选中/取消选中
    
    数据结构：
    {
      pid: '商品ID',
      name: '商品名称',
      price: 价格,
      count: 数量,
      smallImg: '商品图片',
      selected: true/false
    }

5.3 订单管理
    5.3.1 订单创建
        流程：
        1. 从购物车选择商品
        2. 选择收货地址
        3. 选择优惠券（可选）
        4. 计算总价
        5. 创建订单
        6. 支付订单
        7. 更新订单状态
        
        订单数据结构：
        {
          id: '订单ID',
          orderNo: '订单号',
          userId: '用户ID',
          products: [商品列表],
          totalPrice: '总价',
          originalPrice: '原价',
          status: '订单状态',
          address: {地址信息},
          coupon: {优惠券信息},
          discountAmount: '优惠金额',
          createTime: 创建时间,
          updateTime: 更新时间
        }
    
    5.3.2 订单状态
        - pending: 待付款
        - delivering: 配送中
        - completed: 已完成

5.4 优惠券系统
    5.4.1 优惠券类型
        - free: 无门槛优惠券
        - full: 满减优惠券（需要满足满额条件）
    
    5.4.2 优惠券状态
        - available: 可用
        - used: 已使用
        - expired: 已过期
    
    5.4.3 每日更新机制
        实现逻辑：
        1. 使用getTodayDateString()获取今天日期（YYYY-MM-DD）
        2. 检查couponLastDate是否等于今天
        3. 如果是新的一天，清除dailyCouponReceived
        4. 只统计当天的订单消费
        5. 每天可以重新领取已解锁的优惠券
        
        关键代码：
        - checkAndResetDailyData(): 检查并重置
        - calculateTodaySpent(): 计算当天消费
        - 使用订单的createTime判断是否属于今天

5.5 用户认证
    实现方式：
    - 使用本地存储保存用户信息（key: 'userInfo'）
    - 同时保存在app.globalData.userInfo
    - 登录后保存token
    - 退出登录清除用户信息
    
    用户信息结构：
    {
      userId: '用户ID',
      phone: '手机号',
      nickname: '昵称',
      token: '认证token'
    }

六、API接口说明
================================================================================

6.1 基础配置
    服务器地址：http://127.0.0.1:7001
    配置文件：api/api.js

6.2 接口列表
    6.2.1 商品相关
        - getType(): 获取商品类型
          方法：GET
          路径：/type
          返回：商品类型列表
        
        - getProductByType(typeId): 根据类型获取商品
          方法：GET
          路径：/typeProducts
          参数：typeId（商品类型ID）
          返回：商品列表
        
        - getProductByFlag(flags): 根据标志获取商品
          方法：GET
          路径：/flagProducts
          参数：flags（商品标志数组，如['热卖', '上新', '特价']）
          返回：商品列表
        
        - getDetail(pid): 获取商品详情
          方法：GET
          路径：/productDetail
          参数：pid（商品ID）
          返回：商品详情
    
    6.2.2 用户相关
        - userRegister(params): 用户注册
          方法：POST
          路径：/register
          参数：{
            phone: '手机号',
            password: '密码',
            nickname: '昵称'
          }
          返回：注册结果
        
        - userLogin(params): 用户登录
          方法：POST
          路径：/login
          参数：{
            phone: '手机号',
            password: '密码'
          }
          返回：登录结果（包含token和用户信息）
    
    6.2.3 收藏相关
        - getLikeBypid(params): 查询收藏状态
          方法：GET
          路径：/findlike
          参数：{
            pid: '商品ID',
            token: '用户token'
          }
          返回：收藏状态
        
        - like(params): 收藏商品
          方法：POST
          路径：/like
          参数：{
            pid: '商品ID',
            token: '用户token'
          }
          返回：操作结果
        
        - cancelLike(params): 取消收藏
          方法：POST
          路径：/notlike
          参数：{
            pid: '商品ID',
            token: '用户token'
          }
          返回：操作结果

6.3 AI接口（Coze平台）
    配置文件：utils/coze.js
    
    接口信息：
    - API_URL: 'https://api.coze.cn/v3/chat'
    - BOT_ID: '7587462701082411042'
    - 使用流式响应（stream: true）
    - 支持onChunkReceived回调
    
    调用方式：
    const { callCozeAPI } = require('../../utils/coze.js')
    const result = await callCozeAPI(prompt, onUpdate)
    
    返回格式：
    {
      content: 'AI返回内容',
      followUpQuestions: ['后续问题数组']
    }

十三、数据流
================================================================================

13.1 购物流程
    1. 浏览商品（首页/菜单页）
    2. 查看商品详情
    3. 加入购物车
    4. 进入购物袋
    5. 选择商品和数量
    6. 结算
    7. 选择收货地址
    8. 选择优惠券（可选）
    9. 确认订单
    10. 支付
    11. 订单完成

13.2 优惠券领取流程
    1. 进入领取优惠券页面
    2. 查看当天消费金额
    3. 查看可领取优惠券列表
    4. 查看解锁进度
    5. 消费达到解锁条件
    6. 点击领取
    7. 保存到优惠券列表
    8. 第二天自动重置

13.3 搜索流程
    1. 点击搜索框
    2. 显示搜索历史和AI推荐
    3. 输入关键词或点击历史/推荐
    4. 实时过滤商品
    5. 确认搜索
    6. 保存搜索历史

十七、常见问题
================================================================================

17.1 搜索历史不显示
    检查：本地存储中是否有'searchHistory'数据
    解决：清除本地存储或重新搜索

17.2 优惠券不更新
    检查：couponLastDate是否正确
    解决：清除dailyCouponReceived和couponLastDate

17.3 AI推荐不显示
    检查：网络连接和API配置
    解决：检查coze.js中的BOT_ID和API_KEY

17.4 订单数据丢失
    检查：本地存储是否被清除
    解决：重新创建订单
