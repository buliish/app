================================================================================
一、项目概述
================================================================================

1.1 项目简介
    本项目是一个基于微信小程序原生框架开发的咖啡电商小程序，提供商品浏览、
    搜索、购买、订单管理、优惠券领取等完整的电商功能。同时集成了AI智能助手
    功能，提供智能推荐、对话服务和商品推荐。

1.2 核心功能
    - 商品展示与浏览（首页、菜单页）
    - 跨分类商品搜索（支持搜索历史、AI智能推荐、自动跳转分类）
    - 购物车管理（用户数据隔离）
    - 订单管理（创建、支付、查看、状态跟踪）
    - 收货地址管理（用户数据隔离）
    - 优惠券系统（领取、使用、每日更新、消费解锁）
    - 用户登录注册
    - 收藏功能（用户数据隔离）
    - AI智能助手（基于Coze平台，支持商品推荐）

1.3 技术特点
    - 使用微信小程序原生框架，性能优异
    - 统一的UI设计规范，主题色：#0C34BA
    - 本地存储管理，数据持久化
    - 用户数据隔离机制（每个账号独立数据）
    - AI智能推荐功能
    - 每日更新的优惠券系统
    - 登录验证机制（收藏、结算需登录）
    - 跨分类搜索，智能跳转

五、核心功能实现
================================================================================

5.1 搜索功能
    5.1.1 搜索历史
        实现方式：
        - 使用wx.getStorageSync/wx.setStorageSync存储搜索历史
        - 最多保存10条历史记录
        - 自动去重，相同关键词移到最前面
        - 支持删除单条和清除全部
        - 用户数据隔离（每个账号独立的搜索历史）
        
        存储key: 'searchHistory_${userId}'
        数据结构: ['关键词1', '关键词2', ...]
    
    5.1.2 AI智能推荐
        实现方式：
        - 使用Coze AI平台API
        - 点击搜索框时自动加载推荐
        - 推荐5个热门搜索关键词
        - 点击推荐关键词直接搜索
        
        API配置：
        - 文件：utils/coze.js
        - BOT_ID: '7587462701082411042'
        - API_URL: 'https://api.coze.cn/v3/chat'
        - 使用流式响应处理
    
    5.1.3 跨分类搜索（菜单页）
        实现方式：
        - 页面加载时预加载所有分类的商品数据
        - 为每个商品添加分类信息（typeId, typeName, typeIndex）
        - 搜索时在所有商品中过滤（不局限于当前分类）
        - 搜索结果中显示分类标签
        - 点击搜索结果时自动切换到对应分类
        
        核心方法：
        - loadAllProducts(): 加载所有分类的商品数据
        - filterProducts(): 跨分类商品过滤
        - viewDetail(): 从搜索结果跳转到对应分类
        - switchToType(): 切换到指定分类

5.2 购物车功能
    实现方式：
    - 使用app.globalData.cart存储购物车数据
    - 同时同步到本地存储（key: 'cart_${userId}'）
    - 支持添加、删除、修改数量

        - available: 可用
        - used: 已使用
        - expired: 已过期
    
    5.5.3 每日更新机制
        实现逻辑：
        1. 使用getTodayDateString()获取今天日期（YYYY-MM-DD）
        2. 检查couponLastDate是否等于今天
        3. 如果是新的一天，清除dailyCouponReceived
        4. 只统计当天的订单消费
        5. 每天可以重新领取已解锁的优惠券
        
        关键代码：
        - checkAndResetDailyData(): 检查并重置
        - calculateTodaySpent(): 计算当天消费
        - 使用订单的createTime判断是否属于今天
    
    5.5.4 消费解锁机制
        实现逻辑：
        1. 计算用户总消费金额
        2. 计算用户每日消费金额
        3. 根据消费金额判断优惠券是否解锁
        4. 解锁后可以领取优惠券
        5. 每天可以重新领取已解锁的优惠券

5.7 数据隔离机制
    实现方式：
    - 所有用户数据使用 userId 作为存储key的后缀
    - 通过 app.getUserStorageKey(key) 方法生成用户隔离的存储key
    - 格式：${key}_${userId}
    
    隔离的数据类型：
    - 购物车：cart_${userId}
    - 收藏：favorites_${userId}
    - 地址：addresses_${userId}
    - 优惠券：coupons_${userId}
    - 搜索历史：searchHistory_${userId}
    - 每日优惠券记录：dailyCouponReceived_${userId}
    - 优惠券最后日期：couponLastDate_${userId}
    - 选中的购物车商品：selectedCartItems_${userId}
    
    核心方法：
    - getUserStorageKey(key): 获取用户隔离的存储key
    - 登录成功后自动加载用户数据
    - 退出登录时清空全局数据
    
    数据切换机制：
    - 登录成功后调用 initCart() 和 initFavorites() 加载用户数据
    - 退出登录时清空 app.globalData.cart 和 app.globalData.favorites
    - 每个用户的数据完全独立，互不影响

5.8 AI商品推荐

    - 从商品库中匹配相关商品

    关键词提取：
    - 识别常见咖啡、饮品关键词
    - 从AI回答中提取商品名称
    - 支持多种匹配模式
    
    商品匹配算法：
    - 商品名称完全匹配：15分
    - 英文名称匹配：12分
    - 部分匹配：8分
    - 商品标志匹配：6分
    - 描述匹配：4分
    - 匹配度相同时，优先显示热卖商品

    - paymentData: 支付数据（临时）
    - orders: 订单列表（内存中）

7.3 数据持久化策略
    - 用户信息：登录后保存，退出清除
    - 购物车：实时同步到本地存储（用户隔离）
    - 订单：永久保存（通过userId字段区分用户）
    - 地址：永久保存（用户隔离）
    - 优惠券：永久保存（用户隔离）
    - 收藏：永久保存（用户隔离）
    - 搜索历史：最多10条，自动去重（用户隔离）
    - 每日优惠券记录：每天自动重置（用户隔离）
    
7.4 数据隔离实现
    实现原理：
    - 使用 app.getUserStorageKey(key) 方法生成用户隔离的存储key
    - 登录成功后自动加载当前用户的数据
    - 退出登录时清空全局数据
    - 切换账号时自动切换对应的数据
    
    关键代码：
    ```javascript
    // app.js
    getUserStorageKey(key) {
      const userId = this.getCurrentUserId()
      return userId ? `${key}_${userId}` : key
    }
    
    // 使用示例
    const storageKey = app.getUserStorageKey('favorites')
    const favorites = wx.getStorageSync(storageKey) || []
    ```
